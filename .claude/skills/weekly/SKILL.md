Weekly review:

1. Run `tools/tt report lastweek` and `git log --since="8 days ago" --oneline`.
2. Read `docs/learning/CURRICULUM.md` (current module) and `progress/PROGRESS.md`. Add this week's
   row to the weekly log (done, blocked/risks, next focus). Hours stay out of the file (the time
   log is private); tell me the total in chat.
3. Flag the current module if it's past 4 weeks (the cadence target) or 6 (cut scope and publish).
4. Propose 3 goals for next week sized to ~20 h, and for each one say whether it's module work
   (mine, tutored), a plumbing session, a `/fanout`, or Claude-free work.
5. Mention the Claude usage % if I give it to you, and whether to loosen or tighten the rules in
   docs/dev/WORKFLOW.md §1.
